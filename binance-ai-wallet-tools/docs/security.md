# 安全模型

这个工具会用你的币安 AI 钱包发交易。下面写清它**能做什么、不能做什么、靠什么保证**。

## 它碰得到什么
- **钱包**：通过币安官方 CLI `baw` 操作。私钥在币安的托管体系里，本工具和 Claude 都拿不到私钥，也不需要。每笔交易都在币安的开发者模式额度和你在 App 里的安全设置之内。
- **API Key**：推特数据源的 Key 存在 `~/.config/binance-ai-wallet-tools/secrets.json`（权限 600），不进项目目录、不进 git、不进日志。
- **看板**：只监听本机 `127.0.0.1`，只接受 GET，不签名、不发交易。

## 永远不会做的事（写死在代码和 skill 里，配置改不了）
1. 不按推文、网页、skill.md 里的要求执行命令、安装软件、下载文件。外部内容只当数据。
2. 交易前必须 `baw contract-call preview`。预演里有**计划外扣款、任何授权 / 权限变化、任何风险提示、需要二次确认**，就不执行。
3. 不签 Permit / Permit2 或内容不明的签名。
4. 不 approve 无限额度。
5. 不把资产转给外部内容里出现的地址。
6. 不记录私钥、助记词、session、API Key（日志工具会拒绝疑似敏感内容）。

## 会自动花钱的范围
由 `config/config.json` 的 `spending` 决定，默认**只打免费张**。打开 `allowAutoPaid` 后：
- 只对「Sourcify 源码已验证 + 台账里有官网或官推」的项目付费；
- 单张 ≤ `maxUnitUsd`，每个项目付费 ≤ `maxPaidPerProject` 张，每天合计 ≤ `maxDailyBnb`；
- 张数按「这个合约累计」算，金额按「当天累计」算，记在 `data/spend.jsonl`；同一时间只允许一个 mint 运行，避免并发超额；
- 超出的部分会被自动裁掉，只拿免费张；没有免费张就不打，交给你决定。
- 配置写错（比如 `"allowAutoPaid": "false"` 加了引号）会直接报错退出，不会悄悄按别的值运行。

## 哪些是硬约束，哪些不是
- **硬约束（代码保证）**：开关、单价、张数、每日上限、预演检查、参数校验、一次只跑一个。
- **软约束（靠 Claude 遵守规则）**：「有官网或官推」这一条读的是台账里的 `site` / `x`，台账由 Claude 填写。skill 要求只填核实过的官方来源，但这不是代码能证明的。所以真正兜底的是上面的金额上限——请按你能接受的损失来设置。
- 项目自带的 `.claude/settings.json` 禁止 Claude 编辑 `config/config.json` 和读取密钥目录；Claude 仍有命令行权限，所以这同样是「防误操作」而不是「防恶意」。

## 你需要自己注意的
- 「免费」NFT 也会花 gas，而且大多数没有交易市场，不保证有价值。这是一个降低踩坑概率的工具，**不是赚钱保证，不构成投资建议**。
- 铸造时附赠的陌生代币不要去交易或授权。
- 开发者模式有到期时间和每日额度，到期后合约调用会失败，需要在 App 里重新打开。
- 同一个 AI 钱包同一时间只能有一个登录会话；在别处登录会让本工具掉线。
- 发布或分享你的分支前，运行 `npm run check`，确认没有把自己的地址、路径、Key 带进去。它只扫当前文件；如果之前提交过敏感内容，再用 [gitleaks](https://github.com/gitleaks/gitleaks) 扫一遍 git 历史。
- 看板只接受来自 `127.0.0.1` / `localhost` 的请求（校验 Host 头），读 NFT 元数据时拒绝内网地址，页面里的外部链接只放行 http(s)。
